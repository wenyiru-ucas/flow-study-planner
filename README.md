# 🍅 Flow 学习计划助手

**KPI 驱动的学习进度追踪 + 番茄钟 + 行测考场模拟** · 一款为备考人打造的桌面学习管理工具（**针对行测专门优化**）

纯前端 · 零后端依赖 · 数据完全本地存储 · 可打包为 macOS 原生应用（Electron）

## 💡 为什么做这个？

备考是一件需要**长期坚持**的事情。市面上的学习管理工具要么太重（需要注册账号、数据在云端），要么太轻（只能记待办，看不到进步）。

Flow 的核心理念是：

> **把"进度"变成可量化的数字，把"练习"变成可复盘的数据，既可以作为日常备考、工作的帮手，也可以在备考后期，通过“考场模拟”板块进行全真模拟**

- 任务不再只是"待办清单"，而是有**计划进度（序时）vs 实际进度**的 KPI 对比——时刻知道自己超前还是滞后
- 每一轮专注练习（番茄钟）的**用时、正确率、题本**都被自动记录，形成趋势曲线，让你看到自己的进步轨迹
- 专为**行测/公务员备考**设计：考场模拟电子钟、六大模块计时、题本成绩管理

## ✨ 特性一览

| 特性 | 说明 |
|------|------|
| 📊 **KPI 进度追踪** | 每个任务自动计算"序时进度 vs 实际进度"，超前/滞后一目了然 |
| 🍅 **番茄钟 + 分段秒表** | 专注计时 + 可命名分段秒表（练习各模块分别计时） |
| 🏫 **考场模拟** | 全真电子钟（自定义开考时间）+ 六大行测模块计时 + 模考历史记录 |
| 📈 **数据分析** | 8+ 图表：学习时长、标签分布、进度完成率、行测正确率/耗时/趋势 |
| 🎨 **自定义色板** | 标签颜色可手动增删，任务颜色一键锁定 |
| 🤖 **AI 重排** | 输入突发情况，AI 自动调整任务计划（DeepSeek） |
| 🔔 **原生通知** | 番茄钟/考试到时弹出 macOS 系统横幅（即使窗口隐藏） |
| 💾 **数据安全** | localStorage + IndexedDB 自动快照双层备份，支持 JSON 导入导出 |

## 🚀 快速开始

### 方式一：浏览器版（零安装）

```bash
git clone https://github.com/wenyiru-ucas/flow-study-planner.git
cd flow-study-planner
open index.html        # 用 Chrome/Safari 打开即可使用
```

### 方式二：macOS 桌面应用（推荐）

```bash
npm install            # 安装依赖（首次需联网）
npx electron .         # 开发模式运行
```

**打包为 .dmg / .app**：

```bash
npm run build          # 输出到 dist/ 目录
```

打包后拖入「应用程序」文件夹即可。桌面版独享：
- 🖥 菜单栏托盘图标 + 番茄钟实时倒计时
- 🖱 托盘右键菜单（暂停 / 结束 / 再来一组）
- 🔔 macOS 原生系统通知
- ⌨️ 原生菜单栏快捷键（Cmd+1~4 切换页面）

### 数据迁移

浏览器版与桌面版数据相互隔离，迁移方法：
**设置 → 导出 JSON → 新环境 → 设置 → 导入 JSON**

## 📖 功能详解

### 📅 月度规划
- 日历网格 + 任务彩色圆点标记，历史月份折叠可回溯
- KPI 卡片：进行中任务数 / 滞后数 / 今日学习指标 / 连续打卡天数

### 🎯 今日任务
- 任务按「逾期 → 今日 → 即将开始 → 已完成」自动排序
- **每日指标自动锁定**：每天首次加载计算，任务延期自动重新分摊
- 番茄钟结束即时刷新今日学习时长

### 🍅 番茄钟 + ⏱ 秒表
- 专注/休息双模式（时长可调），环形进度动画，支持暂停/继续/最小化
- **分段秒表**：练习时给每个分段命名（如"言语理解"），结束时自动保存
- 结束弹窗可填写**答对 / 题数 / 类别（模块）/ 名称（题本）**，自动计算正确率与单题耗时
- 每次练习记录存入对应任务，随时可修正

### 🏫 考场模拟（行测专用）
- **全真电子钟**：自定义开考时间（12/24 时制），从设定时刻开始走秒
- **模块计时**：政治理论 / 常识判断 / 言语理解 / 数量关系 / 判断推理 / 资料分析，一键分段，同模块自动合并
- **历史记录**：每次模考自动保存，可补填各模块题数/答对数/得分率/试卷名，形成完整复盘档案
- 考试时长到时红色闪烁 + 系统通知提醒

### 📈 数据分析
- 统计周期切换（本周 / 本月 / 本年），所有图表联动过滤
- 行测三大图（正确率 / 单题耗时 / 趋势）数据源 = 考场模拟成绩
- **练习趋势图**：正确率与单题耗时按「类别」聚合为单条曲线，hover 数据点显示具体题本名，精准定位每次波动
- 图表卡片支持**拖拽排序**，把最关心的数据放最上面

### 🎨 标签颜色
- 色板默认为红/黄/蓝/绿四色，**可手动添加任意颜色、删除多余颜色**
- 设置页可为每个标签指定颜色，任务与图表自动跟随
- 手动改色的任务自动锁定，不被标签同步覆盖

### 🤖 AI 重排，方便应对突发情况
配置 DeepSeek API Key 后，输入"下周出差三天"等突发情况，AI 自动分析并给出任务重排建议，并可直接确认执行操作。

## 🛡 数据与隐私

| 项目 | 说明 |
|------|------|
| 存储位置 | 全部数据保存在**本地**（localStorage + IndexedDB），不上传任何服务器 |
| 自动备份 | IndexedDB 快照（自动去抖 + 每日首份 + 上限50份），可手动回滚 |
| 导出导入 | 设置页一键导出 JSON / 导入恢复，跨设备迁移 |
| 隐私保护 | 代码仓库已通过 `.gitignore` 排除个人数据，公开仓库不含任何学习记录 |

> ⚠️ 本项目为**纯本地应用**，AI 功能仅在调用 DeepSeek API 时联网，其余操作完全离线可用。

## 🧰 技术栈

| 层 | 技术 |
|----|------|
| 前端 | 原生 HTML / CSS / JavaScript（无框架，零构建） |
| 图表 | Chart.js 4.x（本地 vendor 包，离线可用） |
| 桌面 | Electron 33（主进程 + contextBridge 安全桥接） |
| 存储 | localStorage + IndexedDB |
| 测试 | 轻量单元测试（`tests.html`，浏览器直接运行） |

**项目结构**：

```
├── index.html          # 应用入口
├── main.js             # Electron 主进程（窗口/Tray/IPC/通知）
├── preload.js          # 安全 IPC 桥接
├── modules/            # 业务逻辑模块（17个）
│   ├── planner.js      # 月度规划
│   ├── pomodoro.js     # 番茄钟 + 秒表
│   ├── exam.js         # 考场模拟
│   ├── analytics.js    # 数据分析
│   └── ...
├── vendor/             # 本地依赖（Chart.js）
└── tests.html          # 单元测试
```
